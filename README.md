# Olist Marketplace Analysis

Анализ данных бразильского маркетплейса Olist: около 100 тысяч заказов за 2016-2018 годы.
Инструменты: Python, pandas, SQL (SQLite).

## Данные
Kaggle: "Brazilian E-Commerce Public Dataset by Olist".
Скачать csv-файлы и положить рядом со скриптами. В репозитории данные не хранятся из-за большого размера.

## Как запустить
1. `python load_olist.py` загружает csv в базу olist.db
2. `python olist_analysis.py` выполняет SQL-запросы и выводит результаты

## Вопросы
1. Как менялась выручка по месяцам?
2. Какие категории товаров приносят больше всего денег?
3. Из каких штатов приходит больше всего заказов?

## Выводы
- Выручка выросла с ~120 тыс. реалов в январе 2017 до ~1 млн в 2018, то есть примерно в 8 раз.
- Пик продаж пришёлся на ноябрь 2017 (Чёрная пятница): около 1 млн реалов.
- 97% заказов доставлено, отменено меньше 1%.
- Топ категорий по выручке: health_beauty (1.26 млн), watches_gifts (1.21 млн), bed_bath_table (1.04 млн). Выручка распределена по категориям равномерно, явной «главной» категории нет.
- Заказы сильно сконцентрированы: штат SP даёт ~42% всех заказов, а три штата (SP, RJ, MG) около 67%.
- Первые и последние месяцы в данных неполные (сентябрь-декабрь 2016 и сентябрь 2018), поэтому в анализ выручки по месяцам не включены.
- Выручка указана в бразильских реалах, считалась только цена товаров (без доставки).

## Рекомендации
- Логистику и склады логично концентрировать в крупных штатах (SP, RJ, MG), где основной объём заказов.
- К ноябрю нужно заранее наращивать запасы и мощности из-за пика Чёрной пятницы.
- Остальные штаты это потенциал для роста, но с меньшим объёмом.
